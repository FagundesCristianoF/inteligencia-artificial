# Inteligência Artificial

English version: README.md

Sistemas Kotlin desenvolvidos na matéria de **Inteligência Artificial** pelo curso
**Engenharia de Computação - Instituto Federal do Sul de Minas Gerais Campus Poços de Caldas**.

## Objetivo

Aplicação de conceitos dos algoritmos utilizados na matéria.

## Gradle

Compilar:

```
gradle build
```

Executar exemplos:

```
gradle runBucket
gradle runHanoi
gradle runTicTacToe
gradle runKnn
gradle runKmeans
```

## Projetos

### 1NN
Algoritmo para classificar utilizando o vizinho mais próximo.

### Problema dos Baldes
Possui dois baldes, um de 3 e outro de 5 Litros e precisa colocar 4 litros no balde de 5 litros.
Utilizando **Busca em Largura** - **Breadth-first search**.

### Hanoi
Problema clássico das torres de Hanoi.

### KMeans e MinMax
K-means e minimax para o jogo da velha.
